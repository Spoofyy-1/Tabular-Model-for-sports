# New historical quote source leads

The [2026-09-25 historical trade audit](HISTORICAL_TRADE_SOURCE_AUDIT.md) adds verified immutable file metadata for a 51.9 MB TimeSeventeen pilot, UTC+8 partition semantics, raw fill-ID requirements and official API limitations. This is a planned coverage audit; no additional sports trades have been collected from that source yet.

Research only, September 25, 2026. No archive datasets were downloaded locally. These are candidates for a bounded hosted audit; coverage is not yet verified.

The strongest lead is [PMXT's Polymarket archive](https://archive.pmxt.dev/Polymarket/v2), explicitly CC BY 4.0 with PMXT attribution. Its [schema documentation](https://archive.pmxt.dev/docs/v2-data-overview) describes received/source timestamps, condition IDs, outcome token IDs, bid/ask arrays on book snapshots and price-change events. A documented public object is `https://r2v2.pmxt.dev/polymarket_orderbook_2026-04-17T12.parquet`. Typical hourly files are 100–400 MB. An initial runner can cap this object at 390 MB and the whole job at 500 MB. Source pages sometimes time out; an unavailable source is a reported gap, not permission to evade restrictions.

The [April 17 Charlotte–Orlando event](https://polymarket.com/zh/event/nba-cha-orl-2026-04-17) supplies a concrete Gamma event slug, `nba-cha-orl-2026-04-17`, and actual player-points/assists/rebounds contracts. Retrieve metadata remotely, join condition/token IDs, then match scheduled time, both teams and unique player identity. Keep snapshots preceding both source and schedule starts. Actual matching row counts require the hosted run. Its inactive-player contracts resolve No, which differs from refunding a sportsbook wager.

PMXT's archive license is distinct from its hosted API terms. The [PendulumFlow mirror](https://archive.pendulumflow.com/formats/v2) retains the archive license and publishes checksums, but reports incomplete market coverage and schema differences. Calculate snapshot best prices from actual bid/ask arrays; do not interpret a delta or trade as a full book. Empty hours, absent assets and stale source timestamps are explicit quality flags. [PMXT's Kalshi listing](https://archive.pmxt.dev/Kalshi) also identifies CC BY 4.0 hourly files in May–June 2026, including small files, but its schema and NBA/NFL coverage have not been verified here.

The [official Polymarket Data API v2](https://data-api.polymarket.com/v2/docs) now documents public unauthenticated `/v2/prices-history`, using outcome token IDs. Its API-description MIT label does not by itself establish a data redistribution license. The [Polymarket Institute guide](https://institute.polymarket.com/data) supports research access and distinguishes global versus US data. Their histories must not be conflated. Neither route establishes executable historical fills.

The [TimeSeventeen dataset card](https://huggingface.co/datasets/TimeSeventeen/Polymarket-v1/blob/main/README.md) provides CC BY 4.0 on-chain trades spanning November 2022–April 2026 with market/token IDs, seconds-based timestamps and fees. It explicitly lacks quotes, cancellations and resting depth, so it is a potential trade audit rather than the preferred quote source. No new verified PrizePicks historical public export was found. None of these candidates is ready for a profitability claim or fills the 2023–2025 NBA/NFL bookmaker prop panel automatically.
