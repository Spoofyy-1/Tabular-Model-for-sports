# Schedule density and observed continuity

The separate **Collect schedule density and continuity CSVs** workflow creates NBA/NFL team/game candidates using the already validated NBA `matchup-36178068271-1` and NFL `matchup-36179718171-1` releases. Real processing occurs only on GitHub-hosted runners. Two pinned archives total 74,729,109 bytes; archive and selected CSV hashes are verified. This collector adds derived fields without making another request to league data endpoints.

The outputs are `nba_team_schedule_candidates`, `nfl_team_schedule_candidates`, an opponent-comparison table for each sport, and separate exclusion audits. Tables are sorted by UTC start, game ID and team. UTF-8 compressed CSV uses `\N` for null and string identifiers. Summary, schema, checksums, input URLs and source rights accompany the archive. Published coverage must be taken from the hosted summary, not estimated here.

New candidate fields count source-listed starts within the previous 72 hours, seven days and fourteen days, retain the interval since the previous listed start, and describe consecutive nominal home/away designations. Counts include the start of each window and exclude the current start. Histories reset at each source season, with flags when a window reaches the first listed game. Unknown timestamp precision, nonreciprocal pairs and simultaneous conflicting fixtures are excluded with the other side of the affected game. Schedule identity checks are independent of current scores and outcome-based boxscore quality flags.

Opponent comparisons contain each team's density/rest-interval values and arithmetic differences. These are observed scheduling proxies; a gap is not verified rest, sleep or recovery. Nominal home/away streaks are not travel itineraries, and unknown neutral-site status is explicit. Missing games or later source corrections can alter these retrospective histories. Actual schedule publication time and completeness remain unverified, so automatic training joins are disabled.

NFL audit fields additionally compare source-listed coaching names, stadium IDs/names, roof and surface with the previous listed game. Coaching streaks count consecutive prior records with the same exact source name, stop at unknown names and reset at source-season boundaries. They are not verified identities, complete employment tenures or coaching philosophies. Stadium name changes need not imply a venue move. Roof records can reflect realized game conditions. All such fields use the `audit_` prefix rather than being presented as historically known pregame inputs.

Development remains split into pre-2024 fitting candidates and calendar-2024 calibration candidates. 2025 onward is separate. No current-game scores, result labels or observed play metrics are included. No model fitting, validation tuning, Azure activity or trading occurs.

Synthetic tests cover strict window boundaries, future/outcome invariance, simultaneous fixtures across season labels, missing timestamp/home/coach values, independent pair validation, season resets, venue renaming, leading-zero IDs and opponent joins. Hosted coverage gates require positive prior-start coverage and reject unexpectedly empty panels.

## Verified hosted coverage

Successful release [schedule-context-36181271988-1](https://github.com/kennynakao/Tabular-Model-for-sports/releases/tag/schedule-context-36181271988-1) contains 64,334 NBA team/game candidates across 32,167 games and 14,034 NFL team/game candidates across 7,017 games. There are 63,550 NBA and 13,204 NFL rows with an earlier listed start in the same source season. Sixty-two NBA and 518 NFL source rows are excluded by the identity/date/season checks; excluded records remain in audit CSVs.

All 14,034 NFL candidates have a source-listed coach name, with 43 changes from the immediately previous listed game inside a source season. This is not a count of all coaching hires: offseason changes, unknown start times and season boundaries are excluded from that comparison. NBA coaching names are unavailable in this source and remain null. The release adds context columns to existing games, not new independent games. Its 15 synthetic checks and hosted coverage checks passed; no training occurred.
